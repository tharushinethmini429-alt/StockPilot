# StockPilot

StockPilot is an inventory management system developed to make everyday stock management easier and more organised.

The system allows users to manage products and categories, record stock movements, monitor inventory levels, and keep track of stock-related activities through a simple dashboard.

## Key Features

- Manage products by adding, updating, viewing, and deleting product details.
- Organise products into categories.
- Record stock-in and stock-out transactions.
- View transaction history with product details and dates.
- Monitor low-stock and out-of-stock products.
- View inventory statistics and charts through the dashboard.
- Configure store information and inventory-related settings.
